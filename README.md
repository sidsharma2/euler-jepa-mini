# Euler-JEPA mini

Physics-grounded, reproducible research software for auditing a small
joint-embedding predictive architecture (JEPA) on a synthetic rotor-dynamics
benchmark.

The accompanying paper is an honest method-development study. It asks whether
a JEPA-style latent objective can learn a useful correction to a calibrated
physics forecast. It does **not** claim to model or validate a real engine.

## Main result

The synthetic benchmark is intentionally simple. A calibrated physics model
already captures much of the dynamics, while the learned models expose a more
interesting limitation: lower latent loss does not guarantee lower trajectory
error, correct ordinary differential equation (ODE) residuals, or preserved
control sensitivity.

At the strongest tested nonlinear discrepancy, the full-trajectory results are:

| Model | RMSE (rad/s) |
| --- | ---: |
| Calibrated physics | 1.1603 |
| Supervised gated recurrent unit (GRU) | 0.1248 |
| JEPA-style hybrid | 0.4933 |

These values are exploratory results from synthetic data. They are not
experimental validation, a general benchmark of JEPA, or evidence of
engine-level predictive capability.

## Repository contents

- `run_experiment.py` — original small synthetic benchmark and JEPA-style model.
- `run_discrepancy_trajectory_training.py` — full-trajectory nonlinear-load experiment used by the paper.
- `run_*.py` — baseline, discrepancy, ablation, sensitivity, and diagnostic experiments.
- `reports/main.tex` and `reports/main.pdf` — the paper source and compiled manuscript.
- `figures/` — editable PGFPlots/TikZ figure sources and rendered figures.
- `results/` — selected machine-readable results and derived tables.
- `provenance/` — public provenance manifest and data-source notes.
- `tests/` — lightweight physics tests.

## Physical model

The benchmark starts with Euler turbomachinery work and angular-momentum
balance:

\[
\Delta h_0 = U\Delta C_\theta,\qquad U=r\omega,
\]

\[
J\frac{d\omega}{dt}
=\dot m r\left(k_u u-k_\omega\omega\right)-c_0-c_2\omega^2.
\]

The data are generated synthetically from this declared model. The short
corrected benchmark uses `k_omega` near `0.01` and a 10-step forecast. The
separate full-trajectory nonlinear-load experiment uses `k_omega = 0.25`, a
20-step context, and a 200-step forecast. The paper now keeps those protocols
explicitly separate.

## Reproduce the core experiment

Create a Python environment and install the dependencies:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

Run the original compact benchmark:

```powershell
python run_experiment.py
```

Run the main full-trajectory experiment:

```powershell
python run_discrepancy_trajectory_training.py
```

Run the tests:

```powershell
pytest
```

The scripts use deterministic seeds where applicable and write derived output
under `results/` and `figures/`. A CUDA GPU is optional; the original run used
CUDA, but the code falls back to CPU.

## Data and provenance

There are no personal measurements, private files, or external raw datasets in
this repository. The benchmark trajectories are synthetic and generated by
the code in this repository. The UIUC airfoil dataset belongs to a separate
airfoil-polar project and is **not** used in this paper or these results.

See [`DATA_SOURCES.md`](DATA_SOURCES.md) and
[`provenance/public_manifest.json`](provenance/public_manifest.json) for the
data classification, generation lineage, software citations, and limitations.

## Paper and scientific status

The paper is intentionally clear about what is incomplete. The current work
does not connect UIUC section polars to the transient rotor model. The next
steps are action-conditioned latent rollouts, varying control inputs during
the forecast, delayed actuation, parameter drift, held-out dynamical regimes,
and eventually experimentally anchored compressor--combustor--turbine data.
The project is ongoing.
